# ЕВРО7 — сайт-визитка (черновик)

Одностраничный сайт транспортной компании ООО «ЕВРО7-НАРО-ФОМИНСКАЯ ЛОГИСТИЧЕСКАЯ КОМПАНИЯ». На сайте компания называется коротко — «ЕВРО7». База — Наро-Фоминск (Московская область).

Чистые HTML + CSS, один маленький скрипт для мобильного меню. Без фреймворков, сборщиков и внешних ресурсов. Чтобы посмотреть, откройте `index.html` в браузере.

> ⚠️ **Перед запуском сайта** удалите из `<head>` в `index.html` строку
> `<meta name="robots" content="noindex">` и пройдите [чек-лист](#чек-лист-перед-запуском).

## Позиционирование

- **Главная услуга** — межрегиональные грузовые автоперевозки по России на собственных тягачах, включая дальние рейсы. Собственные полуприцепы для обычных грузов (типы и количество уточняются).
- **Отдельная услуга** — тяга полуприцепов и цистерн заказчика.
- **Опасные грузы — подтверждение квалификации, а не главная специализация:** «Водители и техника допущены к перевозке опасных грузов. Опыт перевозки технических газов (класс 2) в цистернах заказчика.»

Правила контента, которые нужно сохранять при любых правках:

- У компании **нет собственных цистерн** — нигде не утверждать обратное. Цистерны всегда заказчика.
- **Клиентов не называть** и не намекать на них. Никаких логотипов заказчиков.
- **Цены не публикуются** — только «расчёт стоимости по запросу» и блок «От чего зависит стоимость».
- **Никаких абсолютных обещаний:** «100% гарантия», «0 штрафов», «самые низкие цены», «лучшие на рынке» и т. п.
- **География — только позитивно:** «Работаем в регионах…», «Маршрут уточняйте у диспетчера». Не упоминать регионы, куда не ездим, и причины.
- **Без SEO-переспама:** ключевые фразы не повторять без нужды, текст пишется для человека.
- **Не больше двух видов кнопок действия на экран** (сейчас это «Позвонить» и «Написать на почту»; в контактах — «Построить маршрут»). В остальных блоках — текстовые ссылки на раздел «Контакты», а не новые кнопки.
- **У каждого изображения — осмысленный `alt` на русском.** Плейсхолдеры подписаны через `aria-label`; готовые `alt` для реальных фото есть в комментариях рядом с ними.

## Варианты H1

Сейчас на сайте вариант 1. Альтернативы:

1. **Грузовые перевозки по России из Наро-Фоминска** — коротко, услуга + охват + база.
2. **Межрегиональные грузоперевозки на собственных тягачах — база в Наро-Фоминске** — подчёркивает собственный парк.
3. **Грузовые автоперевозки по России и дальние рейсы из Наро-Фоминска** — подчёркивает дальние рейсы.

H1 меняется в одном месте: `<h1 class="hero__title">` в `index.html`. `Наро-Фоминска` обёрнут в `<span class="nowrap">`, чтобы название не разрывалось по дефису.

## Как заменить контент

**Фото.** Положите в `images/` два варианта каждого снимка: `.webp` и `.jpg` (сжатые; ориентир — до 200–300 КБ, ширина 1200–1600 px для первого экрана и ~800 px для карточек). Замените блок `<div class="ph …">…</div>` на `<picture>`; готовый пример с `alt` есть в комментарии рядом с плейсхолдером:

```html
<picture>
  <source srcset="images/truck-1.webp" type="image/webp">
  <img src="images/truck-1.jpg" alt="Седельный тягач [марка, модель] из автопарка ЕВРО7" width="800" height="600" loading="lazy">
</picture>
```

Для фото первого экрана используйте `fetchpriority="high"` вместо `loading="lazy"`. Чтобы картинка заполняла рамку, добавьте ей в CSS `width:100%; aspect-ratio:4/3; object-fit:cover` (для первого экрана — `4/5`).

**Сканы документов.** Кладите в `images/docs/`: превью (≈300 px по ширине) и полноразмерный файл, превью оборачивайте ссылкой на полный скан — пример в комментарии перед карточками. **152-ФЗ:** на сканах документов водителей закройте ФИО, фото и номера личных документов, если нет письменного согласия на публикацию.

**Схема проезда.** Сделайте скриншот карты (с соблюдением условий сервиса карт), сохраните как `images/map.webp` + `images/map.jpg` и замените `<img src="images/map-placeholder.svg">` на `<picture>`. Ссылка «Построить маршрут» ведёт на Кубинское ш., 5А: `https://yandex.ru/maps/?rtext=~55.4108%2C36.7135&rtt=auto`; если офис по другому адресу, замените координаты (`~` перед координатами означает «от текущего местоположения пользователя»).

**Карточки документов, техники, регионов, вопросов.** Копируйте/удаляйте элементы `<li class="doc">`, `<li class="card card--fleet">`, `<li>` в `.regions`, `<details class="faq__item">` — сетка подстроится сама.

**Логотип.** В шапке замените содержимое `<a class="logo">` на `<img src="images/logo.svg" alt="ЕВРО7 — логотип" width="140" height="40">` (то же в подвале, `span.logo--footer`). Фавиконку замените в `images/favicon.svg`.

## Как заменить стиль

Все цвета, шрифты и основные размеры собраны в начале `css/style.css` в блоке `:root`:

- `--c-ink`, `--c-ink-2` — тёмный фирменный цвет (шапка, первый экран, тёмные блоки, подвал);
- `--c-accent`, `--c-accent-hover`, `--c-on-accent` — акцент (кнопки, метки, полоса над шапкой) и цвет текста на нём;
- `--c-link` — тёмный вариант акцента для ссылок и текста на светлом фоне;
- `--c-bg`, `--c-surface`, `--c-tint`, `--c-text`, `--c-muted`, `--c-line` — нейтральные;
- `--font-body`, `--font-head`, `--font-mono` — шрифты.

Проверьте контрастность текста на кнопке и ссылок (не ниже 4.5:1). Также поправьте `<meta name="theme-color">` в `index.html` под новый тёмный цвет.

**Фирменный шрифт** подключайте только локально: файлы `.woff2` — в `fonts/`, объявление `@font-face` — в `style.css` (пример закомментирован под `:root`), имя шрифта — первым в `--font-body` / `--font-head`. Google Fonts и другие CDN не использовать.

## Ограничения (152-ФЗ) — не нарушать при доработках

- Никаких форм обратной связи и сбора данных; связь только ссылками `tel:` и `mailto:`.
- Никакой аналитики (Яндекс Метрика, Google Analytics и т. п.) и счётчиков.
- Никаких внешних ресурсов: шрифты, иконки, скрипты, стили — только из репозитория. Иконки — встроенные SVG прямо в HTML.
- Никаких встроенных виджетов карт — только статичная картинка и ссылка на Яндекс Карты.
- Персональные данные (ФИО, фото водителей и руководителя) не публиковать без письменного согласия.

Проверить, что страница не делает внешних запросов: в DevTools → Network при загрузке все запросы должны идти к своему домену.

При настройке хостинга можно дополнительно закрепить это заголовком Content-Security-Policy, например: `default-src 'self'; img-src 'self'; form-action 'none'; frame-src 'none'`.
