# ЕВРО7 — сайт-визитка (черновик)

Одностраничный сайт ООО «ЕВРО7-НЛК» (бренд на сайте — «ЕВРО7»): межрегиональные грузовые автоперевозки разных грузов; отдельное направление — перевозка технических газов в цистернах заказчика.

Чистые HTML + CSS, один маленький скрипт для мобильного меню. Без фреймворков, сборщиков и внешних ресурсов. Чтобы посмотреть, откройте `index.html` в браузере.

> ⚠️ **Перед запуском сайта** удалите из `<head>` в `index.html` строку
> `<meta name="robots" content="noindex">` — иначе поисковики не будут индексировать сайт.
> Также замените все `[ЗАГЛУШКА]` (см. ниже).

## Заглушки

Все неизвестные данные помечены текстом `[ЗАГЛУШКА]`. Найти все:

```sh
grep -rn "ЗАГЛУШКА" index.html css images
```

Правила контента, которые важно сохранить при правках:
- компания возит разные грузы; технические газы — отдельное направление, а не единственная специализация;
- у компании **нет собственных цистерн** — для газов цистерна всегда заказчика, «ЕВРО7» даёт тягач и водителя;
- цены не публикуются — везде «Расчёт стоимости по запросу»;
- в «Географии» — только регионы, где работаете, без упоминания тех, куда не ездите, и причин.

## Как заменить контент

**Телефон и почта.** Замените номер во всех `href="tel:+7…"` (формат без пробелов и скобок) и в видимом тексте; почту — во всех `mailto:`. У кнопки «Написать на почту» в первом экране к адресу добавлена тема письма (`?subject=…`) — её можно оставить.

**Фото.** Положите в `images/` два варианта каждого снимка: `.webp` и `.jpg` (сжатые; ориентир — до 200–300 КБ, ширина 1200–1600 px для первого экрана и ~800 px для карточек). Затем замените блок `<div class="ph …">…</div>` на `<picture>`; готовый пример есть в комментарии рядом с каждым плейсхолдером:

```html
<picture>
  <source srcset="images/truck-1.webp" type="image/webp">
  <img src="images/truck-1.jpg" alt="Седельный тягач …" width="800" height="600" loading="lazy">
</picture>
```

Для фото первого экрана используйте `fetchpriority="high"` вместо `loading="lazy"`. Чтобы картинка заполняла рамку, добавьте ей в CSS `width:100%; aspect-ratio:4/3; object-fit:cover` (для первого экрана — `4/5`).

**Схема проезда.** Сделайте скриншот карты (с соблюдением условий сервиса карт), сохраните как `images/map.webp` + `images/map.jpg` и замените `<img src="images/map-placeholder.svg">` на `<picture>`. В ссылке «Построить маршрут» укажите координаты офиса: `https://yandex.ru/maps/?rtext=~55.755819%2C37.617644&rtt=auto` (`~` перед координатами означает «от текущего местоположения пользователя»).

**Карточки документов, техники, регионов.** Копируйте/удаляйте элементы `<li class="doc">`, `<li class="card card--fleet">`, `<li>` в `.regions` — сетка подстроится сама.

**Логотип.** В шапке замените содержимое `<a class="logo">` на `<img src="images/logo.svg" alt="ЕВРО7" width="140" height="40">` (то же в подвале, `span.logo--footer`). Фавиконку замените в `images/favicon.svg`.

## Как заменить стиль

Все цвета, шрифты и основные размеры собраны в начале `css/style.css` в блоке `:root`:

- `--c-ink`, `--c-ink-2` — тёмный фирменный цвет (шапка, первый экран, «География», подвал);
- `--c-accent`, `--c-accent-hover`, `--c-on-accent` — акцент (кнопки, метки, полоса над шапкой) и цвет текста на нём; проверьте контрастность текста на кнопке (не ниже 4.5:1);
- `--c-bg`, `--c-surface`, `--c-tint`, `--c-text`, `--c-muted`, `--c-line` — нейтральные;
- `--font-body`, `--font-head`, `--font-mono` — шрифты.

Также поправьте `<meta name="theme-color">` в `index.html` под новый тёмный цвет и два оттенка `#b5520c` в CSS (тёмная версия акцента для текста на светлом фоне).

**Фирменный шрифт** подключайте только локально: файлы `.woff2` — в `fonts/`, объявление `@font-face` — в `style.css` (пример закомментирован под `:root`), имя шрифта — первым в `--font-body` / `--font-head`. Google Fonts и другие CDN не использовать.

## Ограничения (152-ФЗ) — не нарушать при доработках

- Никаких форм обратной связи и сбора данных; связь только ссылками `tel:` и `mailto:`.
- Никакой аналитики (Яндекс Метрика, Google Analytics и т. п.) и счётчиков.
- Никаких внешних ресурсов: шрифты, иконки, скрипты, стили — только из репозитория. Иконки сейчас — встроенные SVG прямо в HTML.
- Никаких встроенных виджетов карт — только статичная картинка и ссылка на Яндекс Карты.

Проверить, что страница не делает внешних запросов: в DevTools → Network при загрузке все запросы должны идти к своему домену.

При настройке хостинга можно дополнительно закрепить это заголовком Content-Security-Policy, например: `default-src 'self'; img-src 'self'; form-action 'none'; frame-src 'none'`.
